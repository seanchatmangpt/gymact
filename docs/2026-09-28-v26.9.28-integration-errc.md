# v26.9.28 integration, read through ERRC

**Status: analysis grounded in the v26.9.28 branch-integration run.** "Executed"
items below were done and measured in that run; "Proposed" items are not done.
Nothing here claims release standing: exact-head CI has not run.

## Method

ERRC (Eliminate / Reduce / Raise / Create) as in
`2026-08-12-chatman-ecosystem-errc-8020-1000x.md`, applied to what the
integration of ~50 divergent branches actually exposed. Four review lenses were
applied to the same evidence, each asking one question:

| Lens | Question | Law it enforces |
|---|---|---|
| Consequence | Does any claim collapse accepted / changed / verified / scored? | CLAUDE.md consequence law |
| Semantic | Is anything a private ontology where a public term exists? | `.claude/rules/ontology.md` |
| Standing | Is "works" backed by real OCEL, not a green pytest? | `.claude/rules/ocel-standing.md` |
| Boundary | Does explore code sit where only admitted code belongs? | `.claude/rules/explore-exploit.md` |

## Measured facts (this run)

- 53 unmerged remote branches at start; 52 merged, 1 deliberately not
  (`backup/v26.9.25/tmp_t1-probe-gym`, a snapshot of an unrelated temp dir, 709
  conflicting files).
- Of 41 initially-conflicting branches, ~all conflicts were add/add: `main`
  already held a lint-fixed squash of the same code. After format/import
  normalisation only 20 of 139 files in the largest line still differed, and
  the differences were lint refactors (E741 renames, comprehension rewrites).
- `src/gymact` is 86,068 lines; 59 `explore_*` packages hold 22,850 of them
  (about 27%).
- Lint on the merged tree started at 184 errors (main: 16) and is now 0.
- Full suite: all pass except 2 environmental failures (`gh` CLI absent;
  terragoat submodule absent) plus 1 collection error from the same terragoat
  gate.
- One branch (`published` survival/ALOOP line) shipped 32 of 51 files with
  `IndentationError`; it was reverted.
- One branch (policy-ecology) emitted OCEL that failed the official OCEL 2.0
  schema (object-attribute `time` missing; non-string event values). Fixed in
  the emitter, test untouched.

## Eliminate

- **Parallel drafts of the same module.** Each conflict was two versions of one
  file. Proposed: a merge-base rule that a branch whose add/add files are
  `ruff format`-equivalent to `main` is closed, not merged. *Proposed.*
- **Blind "merge all" of preserve/backup refs.** `backup/*`, `preserve/*`,
  `recover/*` are archives, not integration inputs. Proposed: move them under a
  non-`origin/*` namespace or tag them. *Proposed.*
- **Merging a branch a PR calls superseded.** The revert of `research_runtime`
  is the instance. *Executed (reverted).*

## Reduce

- **Lint drift between branches and main.** 184 to 0 (`ruff check src tests`
  clean; the `tau2` availability probes carry justified `noqa`). *Executed.*
- **`explore_*` share of the production tree (27%).** The explore/exploit rule
  says exploration belongs in a lab repo and crosses only after admission.
  Proposed: an admission ledger per `explore_*` package (falsified? public
  ontology profile? Python/Rust projections agree?) and extraction of
  unadmitted packages to the lab repo. *Proposed; not done.*
- **Stale branch count** (94 remote refs). Proposed: delete branches whose tip
  is an ancestor of `main`. *Proposed.*

## Raise

- **Schema conformance of every emitted OCEL.** The policy-ecology emitter was
  the only one found failing, because it had no test against the official
  schema until its branch landed. Proposed: a parametrised court that validates
  every `*_to_ocel` function's output with `gymact.ocel.validate_ocel_log`.
  *Proposed.*
- **Public-API export integrity.** The merge silently dropped 13 `__all__`
  names while keeping their imports; only lint caught it. Proposed: a test that
  every name imported into `gymact/__init__.py` from a `gymact.*` module is
  listed in `__all__`. *Executed:* `tests/test_public_api_exports_chicago.py`
  (AST scan of the real `__init__.py`; mutation-checked by deleting one export,
  which turns it red). The 13 dropped names were also restored.
- **Import-time hermeticity.** Two failures and one collection error are
  environment gates (`gh`, terragoat). They fail loudly rather than skip, which
  matches the standing law. *Executed:* the `gh`-dependent chatman-state test now
  declares `LOCAL_GYM:chatman-state` via `require_standing`: red without consent,
  a named skip with `GYMACT_ALLOW_DEGRADED_STANDINGS`. The terragoat gate is
  unchanged (a real, environment-fixable gap).

## Create

- **A merge court.** A script that, given a branch, reports: add/add files
  format-equivalent to `main`, real content conflicts, syntax errors in
  merged Python (`compileall`), collection errors, and `__all__` drift. The
  broken `research_runtime` package and the dropped exports would both have
  been caught by it before commit. *Proposed.*
- **An ERRC-ledger row per integration** (this document's tables) kept in
  `docs/`, so the next integration starts from measured facts.

## What this does not claim

- No CI ran on the merged head. No release standing is claimed for v26.9.28.
- The survival-runner merge kept `main`'s files. The branch's two CLI tests
  (`gate fails on incomplete corpus`, `manifest then complete observation
  corpus`) exercised a CLI shape that #147 replaced; closure itself is covered
  at library level by `test_survival_observation.py`,
  `test_survival_campaign_observation.py` and `test_survival_dcm_closure.py`.
  A CLI-level incomplete-corpus gate test does not exist on the merged head.
- "Merged" means integrated into `claude/hopeful-turing-59cbos`, not `main`.
- The four lenses are one reviewer applying four checklists, not four
  independent reviewers; none of the findings above has independent review.
